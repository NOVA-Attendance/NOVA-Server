🚀 QUICK START: Enable Email for 2-Step Verification
====================================================

To make verification codes come to users' emails (real 2-step verification):

OPTION 1: Automated Setup (Easiest)
------------------------------------
Run the setup script:
  python3 setup_email.py

Follow the prompts to configure your email.

OPTION 2: Manual Setup
----------------------
1. Create a file named ".env" in NOVA-Server folder

2. Add these lines (replace with your email):
   EMAIL_ENABLED=true
   EMAIL_SMTP_SERVER=smtp.gmail.com
   EMAIL_SMTP_PORT=587
   EMAIL_USE_TLS=true
   EMAIL_SENDER=your-email@gmail.com
   EMAIL_PASSWORD=your-app-password

3. For Gmail:
   - Go to: https://myaccount.google.com/apppasswords
   - Generate an App Password (16 characters)
   - Use that as EMAIL_PASSWORD

4. Restart backend server:
   python3 app.py

✅ DONE! Verification codes will now be sent via email!

⚠️  If email fails, codes will still be shown in console as backup.
